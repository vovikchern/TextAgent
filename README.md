# Текстовый помощник (ProxyAPI)

Консольный текстовый AI-помощник на Python, подключённый к **ProxyAPI** (https://proxyapi.ru).
Общайтесь с нейросетями прямо в терминале — с сохранением контекста диалога и видимыми размышлениями модели.

## Возможности

- 💬 Диалог в консоли с сохранением **истории контекста** между запросами
- 🔀 **Два режима работы** (выбор при запуске):
  - **Думающая модель** (по умолчанию) — `anthropic/claude-sonnet-4-5` через Anthropic Messages (`/v1/messages`) с включённым `thinking` — видны блоки размышлений (reasoning) и расход токенов
  - **Обычная модель** — `openai/gpt-5-mini` через OpenAI-совместимый Chat Completions (`/v1/chat/completions`)
- 🔐 Конфигурация через `.env` (ключ ProxyAPI, названия моделей, бюджет thinking)
- ⚠️ Обработка ошибок запросов и таймаутов, понятные логи
- 🧹 Команды: `exit` — выход (с показом истории), `history` — история, `clear` — очистить

## Быстрый старт

1. Клонировать репозиторий и создать виртуальное окружение:

   ```
   python -m venv venv
   venv\Scripts\activate          # Windows
   pip install -r requirements.txt
   ```

2. Скопировать `.env.example` в `.env` и вписать ключ из
   https://console.proxyapi.ru/keys (виден один раз сразу после создания):

   ```
   PROXYAPI_KEY=sk-...
   ```

3. Запустить:

   ```
   python text_agent.py
   ```

## Актуальные особенности ProxyAPI (сентябрь 2026)

- **Единый API**: один адрес для всех вендоров — `https://api.proxyapi.ru/v1`
  (старые `/openai/v1`, `/anthropic/v1`, `/openrouter/v1` отключаются 01.02.2027).
- **Идентификаторы моделей** всегда с префиксом вендора: `openai/gpt-5-mini`,
  `anthropic/claude-sonnet-4-5` (короткие имена — режим совместимости, не рекомендуется).
- Библиотека Anthropic получает `base_url = https://api.proxyapi.ru` — путь
  `/v1/messages` SDK дописывает сам; заголовок `anthropic-version` подставляется автоматически.
- Размышления: на `/v1/messages` — параметр `thinking` с бюджетом токенов;
  `max_tokens` должен быть **больше** `budget_tokens`.
- Размышления оплачиваются как выходные токены.
